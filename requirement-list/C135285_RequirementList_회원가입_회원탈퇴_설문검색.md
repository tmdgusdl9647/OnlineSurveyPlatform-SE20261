# Requirement List - 회원 가입, 회원 탈퇴, 설문 검색

| No. | Requirement | Use Case(s) |
| --- | --- | --- |
| 1 | 사용자가 온라인 설문조사 플랫폼을 이용하기 위해 회원 가입을 할 수 있어야 한다. | 회원 가입 |
| 2 | 회원 가입 시 ID, 비밀번호, 이름, 전화번호, 이메일을 필수 정보로 입력할 수 있어야 한다. | 회원 가입 |
| 3 | 회원이 언제든지 회원 탈퇴를 할 수 있어야 한다. | 회원 탈퇴 |
| 4 | 회원 탈퇴 시 해당 회원의 모든 이용 권한이 삭제되어야 한다. | 회원 탈퇴 |
| 5 | 회원 탈퇴 시 해당 회원과 관련된 데이터가 삭제되어야 한다. | 회원 탈퇴 |
| 6 | 회원이 설문 검색을 위해 현재 진행 중인 설문, 향후 진행 예정인 설문, 종료된 설문 중 하나를 선택할 수 있어야 한다. | 설문 검색 |
| 7 | 회원이 선택한 설문 상태 조건과 입력한 키워드를 기준으로 설문을 검색할 수 있어야 한다. | 설문 검색 |
| 8 | 회원의 검색 조건에 맞는 설문 리스트가 검색 결과로 출력되어야 한다. | 설문 검색 |
