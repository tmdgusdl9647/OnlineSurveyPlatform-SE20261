# Use Case Descriptions - 설문 등록, 설문 리스트 조회, 설문 응답 통계 조회

## Use case description: 설문 등록

| Actor Action | System Response |
| --- | --- |
|  | 1. 시스템은 설문 등록 화면을 표시한다. |
| 2. 관리자가 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각 등을 입력한다. |  |
| 3. 관리자가 설문 등록 버튼을 선택한다. | 4. 시스템은 설문 등록을 완료한다. |

**Alternative Courses**

- 2a. 관리자가 필수 정보를 입력하지 않은 경우, 시스템은 설문 등록 버튼을 활성화하지 않는다.
- 3a. 관리자가 취소 버튼을 선택할 경우, 시스템은 설문 등록 화면을 닫는다.

## Use case description: 설문 리스트 조회

| Actor Action | System Response |
| --- | --- |
|  | 1. 시스템은 등록된 모든 설문 리스트를 화면에 표시한다. |
| 2. (Extension point: 상세 조회 — 관리자가 [상세] 버튼 클릭 시) |  |
| 3. *(Extension point: 설문 삭제 — 관리자가 [삭제] 버튼 클릭 시)* |  |

**Alternative Courses**

- 1a. 등록된 설문이 하나도 없는 경우, 시스템은 "등록된 설문이 없습니다" 메시지를 표시한다.

**Extensions**

- E1: 설문 상세내용 조회*(extension point: 상세 조회에서 분기)*
    
    
    | Actor Action | System Response |
    | --- | --- |
    | 1.관리자가 특정 설문 항목의 [상세] 버튼을 클릭한다. |  |
    |  | 2. 시스템은 해당 설문의 상세 정보를 팝업 창으로 표시한다. |
    | 3. 관리자가 팝업의 닫기 버튼을 클릭한다. | 4. 시스템은 팝업을 닫고 설문 리스트 화면으로 복귀한다. |
- E2: 설문 삭제*(extension point: 설문 삭제에서 분기)*
    
    
    | Actor Action | System Response |
    | --- | --- |
    | 1.관리자가 특정 설문 항목의 [삭제] 버튼을 클릭한다. | 2. 시스템은 해당 설문을 삭제한다. |
    |  | 3. 시스템은 설문 리스트를 갱신하여 표시한다. |

---

## Use case description: 설문 응답 통계 조회

| Actor Action | System Response |
| --- | --- |
|  | 1. 시스템은 설문 응답 통계 정보 화면을 표시한다. |
| 2. 관리자가 검색 단위 옵션(최근 1주일, 최근 1개월, 최근 1년) 중 하나를 선택한다. |  |
| 3. 관리자가 통계 조회 버튼을 클릭한다. | 4. 시스템은 해당 기간의 전체 설문 수, 종료된 설문 수, 총 응답 수를 화면에 표시한다. |

**Alternative Courses**

- 4a. 해당 기간의 데이터가 없는 경우 각 항목을 0으로 표시한다.
