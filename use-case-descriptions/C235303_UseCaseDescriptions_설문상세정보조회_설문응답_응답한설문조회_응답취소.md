# Use Case Descriptions - 설문 상세정보 조회, 설문 응답, 응답한 설문 조회

---

## Use case description: 설문 상세정보 조회

| Actor Action | System Response |
|---|---|
| | 1. 시스템은 설문 검색 결과 리스트 화면을 표시한다. |
| 2. 회원이 특정 설문을 선택한다. | |
| | 3. 시스템은 설문 상세정보 화면에 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 표시한다. |
| | 4. 시스템은 해당 설문이 현재 진행 중이면 응답 버튼을 활성화하여 표시한다. |
| 5. 회원이 [목록으로] 버튼을 선택한다. | |
| | 6. 시스템은 설문 검색 결과 리스트 화면으로 돌아간다. |

**Alternative Courses**

- 4a. 설문이 진행 예정이거나 종료된 상태인 경우, 시스템은 응답 버튼을 비활성화하여 표시한다.

## Use case description: 설문 응답

| Actor Action | System Response |
|---|---|
| | 1. 시스템은 설문 상세정보 화면에서 응답 버튼을 활성화하여 표시한다. |
| 2. 회원이 [응답하기] 버튼을 선택한다. | |
| | 3. 시스템은 설문 응답 화면에 설문 제목과 각 문항, 응답 항목을 표시한다. |
| 4. 회원이 각 문항에 대한 응답을 선택한다. | |
| 5. 회원이 [응답 제출] 버튼을 선택한다. | |
| | 6. 시스템은 응답이 정상적으로 제출되었음을 알리는 메시지를 표시한다. |
| | 7. 시스템은 설문 검색 결과 리스트 화면으로 돌아간다. |

**Alternative Courses**

- 5a. 응답하지 않은 문항이 있는 경우, 시스템은 미응답 문항이 있음을 알리는 메시지를 표시하고, 회원이 다시 응답을 입력하도록 한다.
- 5b. 회원이 [이전] 버튼을 선택한 경우, 시스템은 설문 상세정보 화면으로 돌아간다.

## Use case description: 응답한 설문 조회 (Base + Extends)

### Main Course

| # | Actor Action | System Response |
|---|---|---|
| 1 | 회원이 응답한 설문 조회를 선택한다. | |
| 2 | | 시스템은 회원이 응답한 모든 설문에 대해 설문 제목, 응답 내용, 응답 일시 등을 출력하는 화면을 표시한다. 진행 중인 설문에 대해서는 [수정] 버튼과 [취소] 버튼을 활성화하여 표시한다. |

### Alternative Courses

- 2a. 회원이 응답한 설문이 없는 경우, 시스템은 응답한 설문이 없음을 알리는 메시지를 표시한다.
- 2b. 종료된 설문에 대해서는 [수정] 버튼과 [취소] 버튼을 비활성화하여 표시한다.

### Extensions

- step2 이후, 회원이 특정 설문 항목의 [취소] 버튼을 선택하면, 시스템은 해당 설문의 응답을 취소하겠냐고 묻는 팝업을 표시하고, 회원이 [응답 취소]를 선택한 경우 응답을 취소한다.
